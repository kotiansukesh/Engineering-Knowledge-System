# 10× Exercises

For every significant system, answer:

| Question | 1× | 10× | 100× |
|---|---|---|---|
| Traffic / workload | baseline | | |
| Latency target | baseline | | |
| Cost | baseline | | |
| Bottleneck | | | |
| Reliability risk | | | |
| Data/storage boundary | | | |
| Architecture change | | | |

Do not redesign merely because scale is larger. Identify the measured or reasoned bottleneck first, then change the boundary or mechanism that addresses it.
