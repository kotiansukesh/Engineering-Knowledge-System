# Source Quality

Use provenance to distinguish durable facts from experience and generated material.

## Source classes

| Class | Use |
|---|---|
| official-docs | product/framework documentation |
| specification | language, protocol or standards specification |
| research-paper | primary research |
| course | structured external learning |
| book | long-form reference |
| blog | secondary technical explanation |
| community | discussion, issue or forum |
| personal-experience | measured or observed engineering experience |
| AI-generated | draft or synthesis that still needs verification |

## Rule

For fast-changing technology claims, prefer **official-docs** or **specification** and record `last-verified`. AI-generated material is a drafting aid, not sufficient provenance for a durable factual claim.
