# Knowledge System

This folder defines how the vault works as a single learning and engineering system.

## Core model

**Knowledge → Practice → Evidence → Capability**

A note explains a concept. Practice tests recognition and implementation. Evidence records what was built, measured or defended. Capability is the ability to apply the concept under changed constraints.

## Four domains

| Domain | Primary question |
|---|---|
| Java | How do I implement and operate backend systems? |
| Coding Patterns | How do I recognize and solve constrained problems? |
| AI | How do I build and operate AI systems? |
| Architect | How do I reason about boundaries, trade-offs and system evolution? |

## Operating rule

Use the **least complicated mechanism that satisfies the requirement**, then create evidence that demonstrates why it works.
