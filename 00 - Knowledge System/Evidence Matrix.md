# Evidence Matrix

Map capability to observable evidence.

| Capability | Minimum evidence |
|---|---|
| Java/backend | implementation + tests + production diagnosis |
| Distributed systems | failure experiment + measured bottleneck + ADR |
| RAG | retrieval evaluation + answer evaluation + failure analysis |
| Agentic AI | tool contract + evaluation + bounded failure behavior |
| AI platform | gateway/platform implementation + SLOs + observability + cost |
| Architecture | requirements + alternatives + ADR + redesign |
| Enterprise AI | end-to-end capstone + governance + migration + defense |

Use this matrix when deciding whether a topic is actually complete.
