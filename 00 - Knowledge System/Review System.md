# Review System

Review should test retrieval, not recognition of the note.

## Suggested loop

**1d → 3d → 7d → 14d → 30d → 60d**

Reset or shorten the interval after a meaningful failure. Extend it after repeated independent success.

## Strong review

- explain from memory
- implement a minimal example
- answer a changed-constraint question
- diagnose a failure
- compare alternatives

## Weak review

- rereading
- copying the note
- repeating a guided solution without variation

Dataview can surface due notes; Tasks should be created only for concrete actions.
