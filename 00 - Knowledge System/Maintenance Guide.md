# Maintenance Guide

## Before editing

- start from latest main
- identify canonical note
- inspect backlinks and dependents
- check version-sensitive claims

## After editing

- validate links
- validate metadata
- inspect orphan/duplicate candidates
- update evidence links
- update `last-verified` for changed version-specific material
- run CI validation

## Cleanup cadence

### Weekly
- review due work
- clear accidental temporary files
- resolve new broken links

### Monthly
- inspect orphan candidates
- inspect duplicate candidates
- review stale technology notes
- consolidate redundant concepts

### Quarterly
- revisit the learning graph
- archive deprecated material
- review build-lab evidence
- refresh portfolio and interview-defense evidence
