# AI Evaluation Architecture

Evaluation is part of architecture because model behavior changes over time.

## Evaluation layers

- offline datasets
- retrieval metrics
- task success
- safety
- groundedness
- latency
- cost
- regression tests
- human review

## Fitness function

Define measurable thresholds before changing prompts, models, retrieval or agent policies.
