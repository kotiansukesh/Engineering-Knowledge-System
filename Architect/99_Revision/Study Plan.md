# Architect Study Plan

## Progression

**Learn → Guided → Blind → Mixed → Interview → Mastered**

### Learn
Read the concept and identify the constraints it addresses.

### Guided
Design with the architecture/style explicitly named.

### Blind
Receive only requirements. Derive the architecture yourself.

### Mixed
Choose between competing architectures and justify the decision.

### Interview
45-minute end-to-end design with injected constraints.

### Mastered
Repeat under a changed scale, failure model, consistency requirement or cost constraint.

## Weekly rhythm

| Session | Activity |
|---|---|
| Day 1 | Concept + decision rules |
| Day 2 | Guided design |
| Day 3 | Trade-off comparison |
| Day 4 | Blind system-design drill |
| Day 5 | Failure/NFR deep dive |
| Weekend | Interview simulation + failure-log review |

## Promotion checklist

- [ ] Requirements clarified before design
- [ ] Back-of-envelope estimates stated
- [ ] At least three measurable NFRs
- [ ] Simplest viable architecture considered
- [ ] Data ownership explained
- [ ] Consistency model justified
- [ ] Failure mode + degraded mode explained
- [ ] Bottleneck identified
- [ ] At least one alternative rejected explicitly
- [ ] Operational burden acknowledged
- [ ] Security boundary identified
- [ ] Observability defined
- [ ] Redesign trigger stated

## Review targets

| Skill | Target |
|---|---|
| Requirements | ≤ 5 min |
| Back-of-envelope | ≤ 5 min |
| High-level design | ≤ 10 min |
| Deep dive | ≤ 10 min |
| Failure analysis | ≤ 8 min |
| Trade-off summary | ≤ 5 min |

Targets are practice constraints, not predictions of interview performance.
