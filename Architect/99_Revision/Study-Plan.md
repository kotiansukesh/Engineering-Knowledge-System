## Weekly Rituals

### Monday: Planning & SR Review
- [ ] Review [[Architect/_templates/Daily-Review-Queue|Daily Review Queue]] for overdue
- [ ] Complete 5-10 spaced repetition cards
- [ ] Plan 3 focus notes for the week

### Wednesday: Deep Dive
- [ ] Complete 1 focus note (Intent + Why it Matters + Diagram + Code + Q&A)
- [ ] Add 5 flashcards to note
- [ ] Cross-link to related patterns

### Friday: Practice & Synthesis
- [ ] Complete 1 practice problem from [[Architect/10_System-Design-Interviews/Practice-Problems/README]]
- [ ] Write interview answer from memory (5 min timer)
- [ ] Update [[Architect/99_Revision/Capstone-Checklist|Capstone Checklist]]

### Sunday: Weekly Review
- [ ] Run [[Master Dashboard|Master Dashboard]] queries
- [ ] Export Anki deck: `python3 export_anki.py`
- [ ] Update `completed` and `reviewed` fields for finished notes
- [ ] Plan next week's focus
