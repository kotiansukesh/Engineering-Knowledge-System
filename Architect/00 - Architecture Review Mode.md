# Architecture Review Mode

Review a design as if you were the architect accountable for its production outcome.

## Review

### Requirements
- [ ] Functional requirements explicit
- [ ] Constraints quantified
- [ ] Assumptions visible

### Architecture
- [ ] Simplest viable architecture considered
- [ ] Boundaries justified
- [ ] Data ownership explicit

### Reliability
- [ ] First failure identified
- [ ] Degraded mode defined
- [ ] Retries bounded
- [ ] Idempotency defined

### Operations
- [ ] Monitoring defined
- [ ] Alerts defined
- [ ] Capacity managed
- [ ] Rollback defined

### Security
- [ ] Trust boundaries identified
- [ ] Authorization model explicit
- [ ] Sensitive data paths known

### Economics
- [ ] Main cost drivers identified
- [ ] Cost at 10× scale estimated
- [ ] Team/on-call burden acknowledged
