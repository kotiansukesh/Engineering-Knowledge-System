# Capability Mapping

A capability describes what the organization must be able to do, independent of implementation.

## Practice

**Business outcome → capability → supporting applications → data → owner → pain/risk**

## Questions

- Which capabilities differentiate the business?
- Which are commodity?
- Where is duplication?
- Which capabilities are constrained by legacy systems?
- Where should investment or simplification occur?
