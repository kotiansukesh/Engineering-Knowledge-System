# Reference Architecture

A reference architecture is a reusable decision baseline, not a mandatory implementation.

## Structure

**Context → boundaries → standard capabilities → approved variations → operational model → evidence**

## Questions

- Which decisions are standardized?
- Which are deliberately left to teams?
- What assumptions make the reference valid?
- How is it versioned?
- What evidence triggers revision?
