# Enterprise Architecture Principles

Good principles constrain decisions without prescribing every implementation.

## Principle format

**Name:**  
**Intent:**  
**Why:**  
**Implications:**  
**Exceptions:**  
**Evidence:**  
**Owner:**

## Examples

- Prefer explicit ownership over shared ambiguity.
- Standardize where the benefit is organizational; allow variation where domain constraints differ.
- Treat security and operability as architecture properties.
