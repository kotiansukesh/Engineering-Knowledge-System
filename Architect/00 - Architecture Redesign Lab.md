# Architecture Redesign Lab

Start from a known design. Change one material constraint. Redesign only what the new constraint demands.

## Constraint changes

- [ ] 10× traffic
- [ ] 10× storage
- [ ] 99.9% → 99.99% availability
- [ ] single region → global
- [ ] eventual → strong consistency
- [ ] synchronous → asynchronous
- [ ] budget reduced by 50%
- [ ] recovery objective tightened
- [ ] regulatory/data residency requirement added
