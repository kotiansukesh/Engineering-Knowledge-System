# 11 JVM & Performance

> Production-oriented JVM knowledge: diagnose first, tune second.

## Topics

- JVM Diagnostics — thread dumps, heap, GC and native-memory investigation.
- Garbage Collection — G1, ZGC, generational behavior and pause/throughput trade-offs.
- JIT and Profiling — warmup, compilation, allocation, JFR and measurement.

## Operating Principle

**Observe → form a hypothesis → measure → change one variable → compare → keep or revert.**

Do not treat JVM flags as configuration folklore.
