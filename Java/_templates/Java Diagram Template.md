# Java Diagram Template

This is a reference file. The actual Excalidraw template is `Java Diagram.excalidraw`.

## Usage

1. `Cmd+P` → `Excalidraw: New from template`
2. Select `Java Diagram`
3. Start drawing

## Template Includes

- **Class** rectangle (blue, solid)
- **Interface** rectangle (green, dashed)
- **Arrow** for relationships (gray)
- **Dark theme** colors matching vault
