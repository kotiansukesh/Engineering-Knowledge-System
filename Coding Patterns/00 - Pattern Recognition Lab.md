# Pattern Recognition Lab

> **Goal:** identify the likely algorithmic pattern before writing code.

## 90-second protocol

1. Required output.
2. Input shape.
3. Constraint that breaks brute force.
4. Repeated work.
5. Maintainable state.
6. Invariant.
7. Candidate pattern and optional secondary pattern.
8. Confidence 1–5.

Do not open the pattern note until the attempt is recorded.

## Recognition scoring

| Score | Evidence |
|---:|---|
| 5 | Pattern + invariant identified immediately |
| 4 | Correct pattern with brief exploration |
| 3 | Correct only after deriving brute force |
| 2 | Correct after a hint |
| 1 | Pattern missed |
