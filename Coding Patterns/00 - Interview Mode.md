# Interview Mode

> Simulate reasoning pressure. Do not expose the pattern name before the attempt.

## 45-minute session

### Problem 1 — Recognition
Target: 10 minutes.

- 90-second diagnosis
- brute force
- constraint filter
- invariant
- implementation sketch

### Problem 2 — Implementation
Target: 15 minutes.

- explain before coding
- implement from memory
- test edge cases
- state complexity

### Problem 3 — Variation
Target: 20 minutes.

Change one constraint: unsorted input, limited memory, possible integer overflow, weighted edges, streaming input, or all answers instead of one.
