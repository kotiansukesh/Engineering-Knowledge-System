## Spaced Repetition Intervals

After solving a problem **cold** (without looking at solution):

| Repetition | Interval | When to Set `sr-due` |
|------------|----------|---------------------|
| 1st | +3 days | `sr-due = today + 3d` |
| 2nd | +7 days | `sr-due = today + 7d` |
| 3rd | +14 days | `sr-due = today + 14d` |
| 4th | +30 days | `sr-due = today + 30d` |
| 5th | +90 days | `sr-due = today + 90d` |

**Rule**: Only advance interval if you solve it *cold* (no hints, no peeking). If you struggle, reset to +3 days.

## How to Mark a Problem Solved

In the pattern note's frontmatter, add:

```yaml
problems-solved:
  - 3
  - 76
problems-solved-dates:
  3: "2026-09-26"
  76: "2026-09-26"
sr-due: "2026-09-29"  # 3 days from now for first rep
```

Or use Tasks plugin: complete the task above → it auto-updates the note if configured.
