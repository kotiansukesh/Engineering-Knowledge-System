## Evidence rule

**Claim → Artifact → Measurement → Failure → Decision → Revisit**

Keep evidence concise and reproducible. Link back to the knowledge note that motivated it.

## Minimum evidence for a major topic

1. **Understand** — explain the mechanism without notes.
2. **Build** — implement the smallest useful version.
3. **Measure** — record the property that matters.
4. **Break** — reproduce one realistic failure.
5. **Decide** — record the alternative and trade-off.
6. **Review** — define when the decision should be revisited.

Do not create evidence documents just to fill folders. One strong experiment is more useful than many empty records.
